# PARES — Jogo da Memória

Jogo da memória interativo, responsivo e sem dependências. Abra `index.html` no navegador ou sirva a pasta localmente:

```bash
git clone https://github.com/Georlan/memory.git
cd memory
python3 -m http.server 8000
```

Depois acesse http://localhost:8000.

## Funcionalidades

- Três dificuldades: fácil (6 pares), médio (8 pares) e difícil (10 pares).
- Cartas animadas, cronômetro, movimentos, acertos e pontuação.
- Recordes locais salvos no navegador (`localStorage`).
- Som opcional, controles de teclado, interface adaptada a celular.
- Botões para reiniciar a partida e embaralhar um novo jogo.

Sem instalação de pacotes, backend, conta ou acesso à internet. Os recordes ficam apenas no navegador usado.
